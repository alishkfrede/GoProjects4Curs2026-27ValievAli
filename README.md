# Практическая работа №5 — Конфигурация Docker и Storage Driver

Работа содержит безопасную подготовку конфигурации и диагностические команды.

ВАЖНО: изменение Storage Driver на рабочем Docker-хосте может сделать существующие локальные образы и контейнеры недоступными. Выполняйте этот пункт на учебной VM/тестовой системе и только после резервного копирования.

`daemon.json` содержит три параметра из задания: `log-driver`, `log-opts`, `live-restore`.

Для фактической смены драйвера используйте `daemon.json.storage-driver.example` как шаблон параметра `storage-driver`, но значение должно соответствовать драйверу, реально поддерживаемому вашей ОС.
