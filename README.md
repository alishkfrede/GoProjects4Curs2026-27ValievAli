# Практическая работа №1 — Docker image, volume, container

## Запуск
```bash
chmod +x run.sh
./run.sh
```

Скрипт выполняет основные пункты задания: загрузку образов, запуск контейнеров, пользовательскую сеть, проверку связи, internal-сеть, tmpfs и общий volume.

## Очистка
```bash
./cleanup.sh
```
