5 задач на горутины

1. Сумма среза двумя горутинами

Числа через запятую. Половины считаются параллельно.

2. Pipeline: N → квадраты

Генератор чисел 1..N → квадратор → результат.

3. Worker pool: 3 воркера, x2

Три воркера читают из одного канала задач.

4. Fan-in: три генератора в один канал

Три источника сливаются в один канал. Порядок случайный.

5. Семафор (2 одновременно) + отмена при >50

Каждое число умножается на 10. Если результат > 50 — вся работа отменяется через context.
