# Практическая работа №4. Docker Compose и многоконтейнерное приложение

## Цель
Научиться описывать приложение в `compose.yaml`, собирать собственный Python-образ и запускать несколько взаимосвязанных сервисов одной командой.

## Задание 1. Flask-приложение

`app.py`, `requirements.txt`, `Dockerfile`, `compose.yaml` находятся в этой папке.

Сборка и запуск:

```bash
docker compose up --build
```

Открыть http://localhost:5000 — отобразится приветствие и hostname контейнера.

## Задание 2. Redis и счётчик посещений

Добавлен сервис `redis` и общая сеть `back-tier`. Приложение увеличивает счётчик `visits` при каждом обращении.

Запуск:

```bash
docker compose up --build
```

Обновление страницы http://localhost:5000 увеличивает `Visits`.

## Ответ на вопрос о сети back-tier

Если отключить сеть `back-tier` только у одного из сервисов — приложение работать корректно не будет. Flask-контейнер не сможет обратиться к Redis по имени `redis`, и операции `r.incr()` будут завершаться ошибкой соединения. Если отключить сеть у обоих сервисов — они также потеряют возможность взаимодействовать. Следовательно, общая сеть `back-tier` для данной архитектуры необходима.
